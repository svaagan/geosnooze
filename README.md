# GeoSnooze – nettsiden

Personvern og hjelp for iPhone-appen GeoSnooze, servert av GitHub Pages. Statiske filer, ingen byggsteg.

- Norsk i rota, de andre språkene under `/<språk>/`.
- `support/` og `personvern/` (og `<språk>/support/`, `<språk>/privacy/`) er adressene i App Store Connect.
- Alle lenker er relative, så sidene virker både under https://svaagan.github.io/geosnooze/ og på et eget domene senere.

Sidene lages av `Felles/skript/nettside.py` fra appens repo, som er privat. Rett ikke HTML-filene her for hånd.
